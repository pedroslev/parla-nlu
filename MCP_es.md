# MCP de Parla

[English](MCP.md) · **Español**

`mcp_server.py` es un servidor MCP con 25 herramientas para que Claude Code, Codex, Claude Desktop, Cursor o
claude.ai armen, validen, prueben, publiquen y analicen bots de Parla. Se corre con `.venv/bin/python mcp_server.py`
(stdio) o `make mcp` (HTTP en `:8001/mcp`).

La documentación completa (herramientas, cómo conectarlo, «Conectar con IA», `PARLA_TOKEN`) está en
[docs/mcp.md](docs/mcp_es.md).
