# Parla MCP

**English** · [Español](MCP_es.md)

`mcp_server.py` is an MCP server with 27 tools that let Claude Code, Codex, Claude Desktop, Cursor or claude.ai
build, validate, test (including `run_tests` for conversation test suites), publish and analyze Parla bots. Run it with `.venv/bin/python mcp_server.py` (stdio) or
`make mcp` (HTTP on `:8001/mcp`).

The full documentation (tools, how to connect it, “Connect to AI”, `PARLA_TOKEN`) is in
[docs/mcp.md](docs/mcp.md).
