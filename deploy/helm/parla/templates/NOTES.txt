Parla {{ .Chart.AppVersion }} is starting ({{ include "parla.image" . }}).

1. Open the admin UI through a tunnel. Use 8000 on BOTH sides (Parla checks Origin against its own port):

     kubectl -n {{ .Release.Namespace }} port-forward deploy/{{ include "parla.fullname" . }} 8000:8000
     # then http://127.0.0.1:8000

2. Create the first user right away (Users → New user): it becomes the owner. Until a user exists,
   anyone who reaches the UI is the owner, with no password. From the API:

     curl -s http://127.0.0.1:8000/api/users -H 'Content-Type: application/json' \
       -d '{"name":"admin","password":"<a long password>","role":"owner"}'
